Stockfish chess engine (WebAssembly build)
==========================================

This folder contains Stockfish 19, compiled to WebAssembly by the Stockfish.js
project, version 19.0.1, "lite single-threaded" flavor:

  stockfish-19-lite-single.js    (sha256 ccb130d7ff29408531c47d859a49f91d59d4f482d05a53eb1a3231a4f624c91a)
  stockfish-19-lite-single.wasm  (sha256 ee4f115bdb2d32cadf96cada104a05b5ec257d7ad6f57582190b49bc71f096de)

The files are unmodified copies from the "stockfish" npm package, version 19.0.1.

Stockfish is free software: you can redistribute it and/or modify it under the
terms of the GNU General Public License, version 3 (see COPYING.txt in this folder).

Complete corresponding source code for these exact files (the Stockfish C++
source, the emscripten glue, and the build script):
  https://github.com/nmrugg/stockfish.js/tree/v19.0.1
Upstream engine:
  https://github.com/official-stockfish/Stockfish

The rest of the Just Chess app talks to the engine only through the UCI text
protocol (postMessage to a Web Worker), as a separate program.
